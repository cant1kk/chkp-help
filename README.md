# ЧКП — Help & Subscriptions

## Что это
Простой сайт с FAQ и системой получения личных ссылок на подписку.

## Как это работает
- Ссылки хранятся в `users.json` в зашифрованном виде (base64)
- Сайт парсит файл и декодирует ссылку по ID пользователя
- Пароль не нужен — дешифровка происходит в браузере

---

## Как добавить пользователя

### Способ 1: через скрипт (рекомендуется)
```bash
node add-user.js <ID> <SUBSCRIPTION_LINK>
```
Пример:
```bash
node add-user.js 5 "vless://abc123@sub.ftp.sh:443?security=tls#user5"
```

### Способ 2: вручную
Открой `users.json` и добавь строку:
```json
{
  "_comment": "Формат: {<ID>: \"<base64-ссылка>\"}",
  "users": {
    "5": "dmxlc3M6Ly9hYmMxMjNAc3ViLmZ0cC5zaDo0NDM/c2VjdXJpdHk9dGxzI3VzZXI1"
  }
}
```
Ссылку можно закодировать так:
```bash
echo -n "vless://abc123@sub.ftp.sh:443?security=tls#user5" | base64
```

---

## Как удалить пользователя
```bash
node remove-user.js <ID>
```

---

## Как посмотреть всех пользователей
```bash
node list-users.js
```

## Требования
- Node.js (для скриптов)
- Любой статический хостинг (GitHub Pages, Netlify, Vercel)

---

## Безопасность
- Ссылки зашифрованы base64 — не видны простым глазом
- Пароль не требуется
- Сайт не индексируется (robots.txt + meta tags)
- Даже если кто-то скачает файл — без декодирования не прочитает
